sweep_along_planar_path sweep_along_planar_path(profile_curves: List[usd_brep._omni_solid.Curve], path_curves: List[usd_brep._omni_solid.Curve], *, move_profile: bool = True, cap_ends: usd_brep._omni_solid.CapEnds = <CapEnds.BOTH: 3>) -> usd_brep._omni_solid.Brep

Pure: returns new Brep; inputs unchanged.

Sweep profile boundary curves along a planar path.

Args:
    profile_curves: Coplanar profile boundary curves. Simple closed
        loops define planar regions using even/odd nesting; open
        profile wires sweep to sheet geometry.
    path_curves: Ordered, connected, coplanar path curves forming an
        open chain or closed loop.
    move_profile: If ``True`` (default), anchor the profile bounding-
        box center to the path start. If ``False``, anchor the first
        point of the first profile curve there instead. Keyword-only.
    cap_ends: ``CapEnds`` selector. ``START`` caps the profile end;
        ``END`` caps the far (path) end; ``BOTH`` (default) caps both;
        ``NONE`` leaves the result open. Closed paths have no
        endpoints, so the selector has no effect. Keyword-only.

Returns:
    Brep: Swept sheet, open shell, or nested solid according to the
        profile topology, path closure, and requested endpoint caps.

Notes:
    For an open path, ``BOTH`` caps plus closed profile loops request
    a nested solid. ``NONE``, ``START``, or ``END`` leave a sheet or
    open shell. A closed path has no endpoint caps and requests a
    nested solid when its swept boundary closes. Nested bounded
    regions alternate between material and void from the outside in.
    A manifold boundary with no material region is rejected.
    Tangent-discontinuous path joins use sharp, mitered transitions;
    rounded corners are not inserted. Author the rounded motion as
    tangent-connected arc or spline path curves when needed.

See Also:
    pipe_sweep: Specialized circular cross-section along a path.
    curve_sweep: Sweep with optional scale curves.

Wraps: SmApiCreateSweepAlongPlanarPath
