create_planar_faces create_planar_faces(curves: List[usd_brep._omni_solid.Curve]) -> usd_brep._omni_solid.Brep

Consumes: curves; returns new Brep.

Build a sheet-body Brep made of planar faces from one or more closed
planar curve loops.

Args:
    curves: Coplanar curves forming one or more closed loops. Curves
        may be supplied in any order and any orientation, but they
        must not intersect each other and each endpoint must be
        coincident with exactly one other endpoint. Consumed on
        success: the new faces use them, so do not reuse them.
        On failure, the curves remain owned by the caller.

Returns:
    Brep: sheet-body Brep whose faces are the planar regions bounded
    by the input loops.

Notes:
    The plane of the result is inferred from the input curves; do not
    pass a plane normal. Multiple coplanar loops produce one face per
    loop (or with-holes faces if loops nest), all packed into a single
    Brep. Returns a sheet body (open shell), not a manifold solid -
    use ``linear_sweep`` to extrude into a solid.

See Also:
    create_plane: Single-rectangle planar sheet.
    linear_sweep: Solid extrusion of a closed profile.

Wraps: SmApiCreatePlanarFaces

create_circle create_circle(center: tuple, radius: float) -> usd_brep._omni_solid.Circle

Create an analytic circle in the XY plane.

Args:
    center: Center of the circle as ``(x, y, z)``. Each coordinate must
        be a valid double in ``[-1e18, 1e18]``. The circle lies in the
        plane Z = ``center.z``.
    radius: Radius of the circle. Must be a valid double in
        ``[-1e18, 1e18]`` and greater than ``SM_EFF_ZERO`` (1e-12).
        An out-of-range ``center``/``radius``, a ``radius`` at or below
        1e-12, or a center whose magnitude dwarfs the radius so the
        extents collapse in double precision (e.g. ``center=(1e18,0,0)``
        with ``radius=1``) raises ``RuntimeError``
        (``SM_ERR_INVALID_INPUT``).

Returns:
    Circle: closed analytic circle. It is a ``BSplineCurve`` (so it
        works anywhere a curve is accepted) and additionally exposes
        ``center()``, ``radius()``, ``normal()``, ``x_axis()``, and
        ``y_axis()``.

Notes:
    The circle is constructed in the world XY plane and translated to
    ``center`` (``x_axis`` = +X, ``y_axis`` = +Y, ``normal`` = +Z).
    For circles in non-axis-aligned planes use the C-API overload
    that takes an explicit axis placement (not currently bound).

See Also:
    create_arc: Open circular arc with start/end angles.
    create_ellipse: Ellipse with two principal radii.

stitch_into_solid stitch_into_solid(brep: usd_brep._omni_solid.Brep) -> tuple

Mutates: brep; returns (brep, is_solid, stitched_edges, max_vertex_gap, max_edge_gap).

Stitch a Brep aiming for a manifold solid result.

Args:
    brep: Brep to stitch in place. Typically a collection of loose
        faces from an import.

Returns:
    tuple[Brep, bool, int, float, float]: ``(brep, is_solid,
    stitched_edges, max_vertex_gap, max_edge_gap)`` where
    ``is_solid`` is ``True`` only if every edge ended up shared by
    exactly two faces. The first element is the same brep handle
    (for chaining).

Notes:
    Uses the kernel default tolerance. If ``is_solid`` is ``False``
    the gap values tell you how much room the unstitched edges
    needed - either widen tolerance with ``stitch_into_shell`` or
    diagnose the geometry directly. Common failure causes: gaps
    larger than tolerance, overlapping faces, or non-manifold
    topology (more than two faces sharing an edge).

See Also:
    stitch_into_shell: Looser tolerance variant.
    stitch_advanced: Per-flag control over the stitch.
    is_manifold_solid: Final validation check after stitching.
    unify_normals: Make face normals consistent post-stitch.

Wraps: SmApiStitchIntoSolid
