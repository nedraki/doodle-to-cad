tessellate tessellate(brep: usd_brep._omni_solid.Brep, *, chord_height_tolerance: float = 0.0, curve_angle_tolerance_deg: float = 25.0, surface_angle_tolerance_deg: float = 25.0, max_edge_length: float = 0.0, max_aspect_ratio: float = 0.0, allow_partial: bool = False, return_failures: bool = False, return_report: bool = False) -> object

Pure: returns new PolyBrep; inputs unchanged.

Tessellate exact Brep NURBS geometry to a triangular ``PolyBrep`` mesh.

Args:
    brep: Source Brep. Not modified.
    chord_height_tolerance: Maximum allowed distance between the
        triangle mesh and the true surface, in modeling units.
        Smaller positive values produce a finer mesh.
        Defaults to ``0`` (disabled).
        Typical ranges: ``0.001`` for high-quality rendering,
        ``0.01`` for general visualization, ``0.1`` for preview.
        Keyword-only.
    curve_angle_tolerance_deg: Curve tangent angular tolerance.
        Defaults to ``25``. ``0`` disables the curve angular criterion.
        Keyword-only.
    surface_angle_tolerance_deg: Surface angular tolerance.
        Defaults to ``25``. Smaller positive values refine curved
        faces; ``0`` disables this angular criterion. Keyword-only.
    max_edge_length: Edge-length subdivision target, in modeling
        units. It drives edge sampling and face subdivision and is
        not a hard cap: final triangle edges can be somewhat
        longer. ``0`` (default) disables it. A negative value
        selects an automatic target derived from model size.
        Keyword-only.
    max_aspect_ratio: Aspect-ratio target for the cells a surface is
        subdivided into before triangulation. It does not limit the
        aspect ratio of the final triangles, which can still be long
        and thin. ``0`` (default) disables it. Keyword-only.
    allow_partial: Retain available faces when some faces fail.
        Defaults to ``False`` (raise instead). Kernel and output errors
        raise in either mode. Requires return_failures or return_report.
        when enabled; otherwise raises ValueError. Keyword-only.
    return_failures: Return ``(mesh, failures)`` with a list of dictionaries.
        Each contains ``face_index`` (input faces() order), ``stage``
        (boundary_preparation, face_tessellation or polygon_output),
        and kernel ``status`` / ``status_name``. Defaults to ``False``.

    return_report: Return (mesh, report) with face failures and nonfatal
        edge-incidence diagnostics; defaults to False and takes precedence
        over return_failures. These are not full solid-validity checks.

Returns:
    PolyBrep: triangulated mesh approximating the Brep within
    the supplied tolerances, or ``(mesh, failures)`` when
    ``return_failures=True`` with the first failure per source face.
    Returns ``(mesh, report)`` instead when ``return_report=True``.

Raises:
    TessellationError: Carries report, failures, status and status_name, including
        when strict mode rejects partial output.

Notes:
    Triangle count grows roughly quadratically as
    ``chord_height_tolerance`` is tightened. Pair this with
    ``poly_brep_volume_via_api`` for mass-property checks on the
    mesh, or with the ``poly_boolean_*`` family for
    polygon-mesh CSG.

See Also:
    poly_brep_is_manifold_via_api: Manifold check on the mesh.
    poly_brep_volume_via_api: Volume of the tessellated mesh.
    compute_volume: Exact volume of the source Brep.
    poly_boolean: Boolean ops on tessellated meshes.
    usd.export_mesh: Round-trip the mesh through USD.

Wraps: SmApiTessellate

boundary_loops boundary_loops(self: usd_brep._omni_solid.Face) -> list

Pure: returns list; inputs unchanged.

Return the oriented boundary loops of this face.

Returns:
    list[list[tuple[Edge, bool]]]: Boundary loops in SMLib order,
        with the outer loop first. Each item is ``(edge, forward)``;
        ``forward=True`` traverses from ``edge.start_vertex()`` to
        ``edge.end_vertex()``, and ``False`` traverses in reverse.

Notes:
    A closed loop's starting occurrence is unspecified. Relative
    to the parent surface's parameterization, the outer loop is
    counterclockwise and inner loops are clockwise. An edge can
    occur more than once, for example at a periodic seam. A
    vertex-only inner loop is represented by an empty list.

    The lists and direction flags are snapshots; each ``Edge`` is
    borrowed from the owning Brep. Do not use returned edges after
    that Brep is consumed, deleted, or changed by a topology-
    modifying operation. Query the face again after such changes.

Wraps: SmApiFaceGetBoundaryLoops
